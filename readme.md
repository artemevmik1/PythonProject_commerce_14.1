## 📝 Описание проекта

Проект представляет собой базовую систему для управления товарами и категориями. Он включает:

- **Класс `Product`** - для описания товаров
- **Класс `Category`** - для группировки товаров по категориям
- **Загрузку данных** из JSON файлов
- **Счетчики** категорий и продуктов

## 🚀 Функциональность

### Основные возможности

1. **Управление продуктами**
   - Создание товаров с названием, описанием, ценой и количеством
   - Хранение информации о товарах

2. **Управление категориями**
   - Создание категорий с названием и описанием
   - Добавление товаров в категории
   - Автоматический подсчет количества категорий и товаров

3. **Работа с JSON**
   - Чтение данных из JSON файлов
   - Создание объектов из JSON данных
